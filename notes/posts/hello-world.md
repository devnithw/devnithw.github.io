# Hello, World

This is the first note on this site.

To add a new note:

1. Drop a `.md` file into `notes/posts/`.
2. Add an entry to `notes/notes.json` with the `file`, `title`, and `date`.

That's it — no build step required.

## Markdown works as expected

You can use **bold**, *italic*, [links](https://devnithw.github.io), and:

- bullet points
- `inline code`
- code blocks
